IWP Community Connections M6.6

Email Templates:
- Built-in templates for three-day, day-before, weather, location change, cancellation, and thank-you messages
- Save and delete custom templates in the organizer's browser
- Placeholder support for participant first name, adventure, date, time, location, address, and organizer
- Email preview with sample participant values
- Server-side placeholder replacement for every recipient before sending

Deployment:
- Apps Script requires clasp push and a new deployment version
- Landing project requires Cloudflare Pages deployment
