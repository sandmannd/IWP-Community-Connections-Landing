IWP Community Connections — M6.14 Final Organizer Usability

Landing repository only.

Changes:
- Mobile organizer menu now closes with Escape, outside click, and returns keyboard focus correctly.
- Analytics has a distinct service-error state with Try Again instead of incorrectly presenting every failure as a sign-in problem.
- Secure QR Check-In now distinguishes sign-in problems from invalid/service failures and provides retry/back navigation.
- Registration Manager empty states distinguish "no registrations yet" from filtered-out results.
- Registration Manager cancel/delete adventure actions now use accessible Community Connections dialogs instead of browser confirm/prompt boxes.
- Permanent delete still requires typing DELETE.
- Builder save/status messages announce updates to assistive technology.
- No Apps Script/backend or registration/check-in business logic changed.
